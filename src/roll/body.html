PUSH TO POWER BI
Star-schema XLSX export — all facilities, actuals + forecast in one file
▾ WHAT GETS EXPORTED
DIMENSIONS
dim_date (contiguous calendar) · dim_facility · dim_element · dim_product · dim_silo_link · dim_scenario · dim_plan_version
FACTS
fact_production · fact_inventory · fact_demand · fact_unloading · fact_rail_movement · fact_stop_events · fact_service · fact_rail_sim · fact_vessel_call · fact_silo_transfer · fact_sof_period · fact_laytime
Every fact row is tagged with scenario_type = actual or forecast and stamped with a scenario_run_id + as_of_date. Open the file in Power BI and build relationships from each fact's element_id / facility_id / product_id / date back to the dim_* tables.
◆ Scope: actuals span every facility in the catalog. Forecast rows only cover the facility the simulation last ran for (—) — run a sim for each facility you want forecast data on before exporting.
▾ POWER BI MODEL HINTS
• In Power BI, mark dim_date.date as a date table.
• Relate facts to dimensions: fact_*.date → dim_date.date, .element_id → dim_element.element_id, .facility_id → dim_facility.facility_id, .product_id → dim_product.product_id.
• Filter visuals by scenario_type to switch between an actual line and a forecast line on the same chart.
• Multiple exports can coexist — slice by scenario_run_id to compare runs.
